# sermarya2.github.io

Portfolio de **Sergio Martín Yagüe**, Data Scientist (ML / IA aplicada) en Valencia.

**→ https://sermarya2.github.io**

La web se "despliega" delante de quien la visita, como un pipeline de ML: ingesta, limpieza, features, modelo, evaluación y despliegue. Cada etapa del log ejecuta código real sobre los datos de la página (cuenta los registros, ordena la trayectoria por fecha y agrupa las habilidades).

- Castellano / English, vista recruiter / técnica y una paleta de comandos (pulsa `/`).
- HTML, CSS y JavaScript en un solo archivo, sin frameworks ni dependencias.
- Respeta "reducir movimiento" y siempre se puede saltar la animación.
